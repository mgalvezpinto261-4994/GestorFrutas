# GestorFrutas

Proyecto simple en Java para gestionar operaciones con frutas.

Instrucciones rápidas:

- Compilar:
  ```bash
  javac *.java
  ```
- Ejecutar:
  ```bash
  java GestionFrutas
  ```

Archivos principales:
- `FuncionesFrutas.java` - funciones auxiliares
- `GestionFrutas.java` - programa principal
